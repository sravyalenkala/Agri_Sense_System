Agri Sense:IoT-Based Agriculture Monitoring System 🌱

Agri Sense is an innovative web-based application powered by the MERN stack (MongoDB, Express.js, React.js, Node.js) designed to revolutionize agricultural monitoring. By leveraging IoT devices, this platform provides real-time data, automates essential processes, and empowers farmers with actionable insights to boost crop productivity and farm sustainability.   

🌟 Key Features :-   
Real-Time Monitoring: View live data from sensors tracking temperature, humidity, soil moisture, and light intensity.   

Smart Automation: Automatically controls hardware like fans, water pumps, and lighting systems based on real-time sensor thresholds.   

Data Visualization: Interactive charts and graphs to monitor environmental trends over time.

Remote Access: Monitor and control farming devices from anywhere using a simple web interface.

🎯 How It Works:-

Humidity and Temperature Control:Uses DHT11 IoT sensors to monitor the environment and automatically activate cooling fans via a relay module when thresholds are exceeded.

Soil Moisture Management: A smart irrigation system that reads soil moisture levels and automatically triggers water pumps to prevent under or over-watering.

Light Intensity Adjustment: Uses LDR (Light Dependent Resistors) to measure natural light and automatically adjust artificial lighting to optimize plant growth.

🛠️ Tech Stack :-

Frontend: React.js (UI) and Axios (API communication)

Backend: Node.js and Express.js (RESTful APIs)

Database: MongoDB (Stores sensor data, user profiles, and historical trends)

IoT Hardware: ESP8266, Arduino Nano, DHT11 Sensor, Soil Moisture Sensor, LDR

🏗️ Future Enhancements:-

Push Notifications: Real-time mobile alerts for critical thresholds via Firebase Cloud Messaging (FCM).

Machine Learning: Implementing predictive models to forecast optimal watering schedules and environmental conditions based on historical data.

Data Export: Enable CSV exports of historical crop data for offline analysis.

Role-Based Access: Dedicated dashboard views for admins vs. general farm workers.
